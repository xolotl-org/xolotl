# Nexus Manual

Nexus is a capability runtime for model-backed applications. It maps model
inference, tool calls, memory, state, and outside systems into `effect://` and
`state://` resources so programs access them through handles compiled by
`open()`. Nexus supplies the execution boundary between model calls, tool
execution, long-lived state, and external protocols. Model training,
application UI, and business logic stay outside this runtime.

This manual is the public narrative documentation for the implemented runtime.
It is separate from Rust API reference pages:

- Use this manual to understand the runtime model, operational boundaries, and
  how the workspace fits together.
- Use Rustdoc for crate, module, type, trait, method, and error contracts.
- Use `examples/` and crate tests for runnable usage patterns as they are added.

Chinese manual HTML, after running `mdbook build docs/zh-CN`:
[`docs/zh-CN/book/index.html`](../zh-CN/book/index.html).

external adapters, and workspace map. Then read [Runtime Model](runtime-model.md)
and [Capability Model](capability-model.md) before implementation details. These
pages define the terms used by the rest of the manual.

## Documentation Layers

The public documentation has three layers:

| Layer | Location | Purpose |
| --- | --- | --- |
| Overview | `README.md` | Project summary, build commands, run commands, and documentation entry points. |
| Manual | `docs/src/*.md` | Human-readable runtime concepts and operational behavior. |
| API reference | `target/doc/` | Rust crate and item contracts generated by `cargo doc`. |

Install mdBook when needed:

```sh
cargo install mdbook
```

Generate the API reference:

```sh
RUSTDOCFLAGS='-W missing-docs' cargo doc --workspace --no-deps
```

Then open `target/doc/index.html`.

If `mdbook` is installed, build this manual with:

```sh
mdbook build docs
```

Build the Chinese manual with:

```sh
mdbook build docs/zh-CN
```

Preview either manual locally with `mdbook serve docs` or
`mdbook serve docs/zh-CN`. The Chinese book sets `language = "zh-CN"` and uses
`docs/zh-CN/theme/cjk.css` for CJK typography.

Without `mdbook`, the files under `docs/src/` are still plain Markdown and
can be read directly.
