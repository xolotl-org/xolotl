# 安全边界

Nexus 的安全边界由运行时路径执行。文档只描述这些路径的公开行为。

## 授权

授权范围从 `Grant` 开始，在派生或请求准入时衰减，并由 `open()` 编译成某个进程持有的 `Handle`。数据平面在分派前检查句柄所有者、存活状态、方法权限和剩余策略。

`state://kernel/*`、`state://vault/*` 和 `state://fact/*` 等内核保留前缀只接受内核写入。控制台管理状态按路径做准入，管理动作使用固定描述符。

## 来源链与污点

值通过 `TaintSet` 携带来源链。污点来源包括作者常量、模型输出、入站事件、抓取内容和受保护来源。操作输入会把污点传播到输出；状态存储 `TaintedValue`，因此来源链会跨状态写入和读取保留。

策略可以基于来源链做决定。例如，如果出站操作的输入来源链接触过受保护来源，该操作可以被拒绝。

## 敏感值

敏感值限制为脱敏元数据或引用后才能进入操作输入、状态、事实记录或跟踪。

控制台认证会写入脱敏后的网关审计事实记录。配对原始敏感值在配对驱动内生成，只通过一次性展示边界离开；记录的操作只携带哈希/校验和元数据。控制台协议声明了敏感值托管动作，但当前宿主会阻止原始敏感值显示，并审计这次尝试。

## 控制台边界

HTTP 用于健康检查和认证引导。登录后的管理路径运行在控制台 WebSocket 上，使用固定动作描述符和流描述符。客户端提交由描述符命名的动作。

管理动作仍经过授权、状态、CAS、可见性、审计和运行时操作路径。受保护载荷视图需要显式可见性元数据，例如 scope、justification 和 TTL。

## 驱动边界

标准终端驱动直接执行 argv，从不通过 shell。命令必须通过拒绝列表、允许列表和高风险审批检查。

抓取驱动在发出请求前拒绝回环地址、私有网络地址、`.local`、`.internal` 和非 HTTP(S) 目标。

这些检查是运行时门槛。运行不可信代码时仍需要操作系统或容器级隔离。
