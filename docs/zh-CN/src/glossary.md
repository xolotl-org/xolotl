# 术语表

中文手册优先使用中文术语。Rust 类型名、Rust 包名、配置键、协议字段、命令和路径保持原文，方便回到代码中查找。

| 中文译名 | 原文或代码名 | 说明 |
| --- | --- | --- |
| 模型应用 | model-backed application | 使用模型推理、工具调用、状态和外部协议完成任务的应用。 |
| 能力运行时 | capability runtime | 把模型推理、工具、状态和外部系统映射为可授权资源，并执行这些资源调用的运行时。 |
| 运行时 | runtime | Nexus 执行进程、操作、策略和事实记录的核心系统。 |
| 工作区 | workspace | 这个 Rust 多包仓库。 |
| Rust 包 | crate | Cargo 管理的 Rust 包。表格中也会直接写 Rust 包名。 |
| 进程 | `Process` | 运行时中唯一的主动实体，拥有句柄并发起操作。 |
| 资源 | `Resource` | 被操作、授权、审计并绑定到驱动的对象。 |
| 效果 | effect | 通过 `effect://...` 资源暴露的外部或内置能力。 |
| 接口 | `Interface` | 描述资源可用方法、输出模式、纯度和成本模型。 |
| 驱动 | `Driver` | 实现接口方法的执行组件。 |
| 绑定 | `Binding` | 把资源连接到本地驱动或远端实现的声明。 |
| 句柄 | `Handle` | `open()` 编译出的资源访问凭据，包含资源、权限、驱动计划和策略信息。 |
| 操作 | `Operation` | 发生副作用或需要记录尝试的运行时调用。 |
| 结果 | `Outcome` | 操作或程序步骤返回的结果。 |
| 事实记录 | `Fact` | 一次操作尝试的只追加持久记录。 |
| 事实流 | Fact stream | 用于恢复、审计、跟踪和解释的事实记录序列。 |
| 能力 | capability | 描述可被授权的操作类别。 |
| 能力字面量 | capability literal | 形如 `perform://...`、`read://...` 的授权字符串。 |
| 授权范围 | authority | 进程当前可行使的能力集合及其约束。 |
| 授权记录 | `Grant` | 向进程授予资源选择器、权限和约束的记录。 |
| 权限 | rights | 方法位图和委托等传播标志。 |
| 授权衰减 | attenuation | 派生进程或处理请求时缩小授权范围。 |
| 选择器 | selector | 匹配资源路径的授权条件。 |
| 策略 | policy | 对打开句柄或执行操作施加的规则。 |
| 策略快照 | `PolicySnapshot` | 策略源编译后的不可变表示。 |
| 剩余策略 | residual policy | 打开时无法完全决定、需要执行时再检查的策略部分。 |
| 准入 | admission | 请求或状态路径进入运行时前的允许/拒绝判断。 |
| 控制平面 | control plane | 解析、校验、名称解析、策略编译和绑定解析所在的平面。 |
| 数据平面 | data plane | 用已编译句柄执行操作的热路径。 |
| 扩展平面 | extension plane | 把外部系统映射到运行时模型的平面。 |
| 程序平面 | program plane | 表示并推进可恢复工作的平面。 |
| 提供方 | Provider | 暴露效果处理器的扩展角色。 |
| 来源 | Source | 把入站事件写入状态流的扩展角色。 |
| 网关 | gateway | 把外部协议适配为 Nexus 进程执行的组件。 |
| 控制台 | console | 管理运行时状态和会话的 Web 控制台后端及其协议。 |
| 程序网关 | program gateway | 接收外部程序提交，并通过 `Gateway` trait（特征）运行 `DoNode` 的入口。 |
| 控制台协议 | Console Protocol | 控制台客户端使用的 HTTP 认证和 MessagePack WebSocket 管理协议。 |
| 状态 | state | 通过 `state://` 和状态驱动访问的可变数据。 |
| 状态流 | state stream | 来源投影或订阅使用的状态事件序列。 |
| 来源链 | provenance / lineage | 值的来源信息，用于审计和策略判断。 |
| 污点 | taint | 附着在值上的来源标签集合。 |
| 受保护来源 | protected source | 需要额外可见性、审批或策略限制的数据来源。 |
| 重放 | replay | 使用事实记录恢复或避免重复执行已完成操作。 |
| 恢复 | recovery | 崩溃后根据事实记录重建程序进度。 |
| 幂等键 | idempotency key | 用于对幂等效果去重的键。 |
| 预备记录 | write-ahead record | 发出非幂等效果前先写入的恢复记录。 |
| 引导 | bootstrap | 宿主启动时加载基础配置和初始凭据的过程。 |
| 敏感值 | secret | 原始秘密内容，限制在凭据或一次性展示边界。 |
| 脱敏 | redaction | 用安全元数据或引用替代原始敏感值。 |
| 宿主 | host | 运行 `nexusd` 并承载运行时的进程环境。 |
